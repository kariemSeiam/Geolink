## What we do

No jargon — just what goes in, and what comes back out.

| You send | We return |
|---|---|
| `"Eiffel Tower"` | `48.8584° N, 2.2945° E` |
| `48.8584, 2.2945` | `"Champ de Mars, 5 Av. Anatole France, Paris"` |
| Point A + Point B | Distance, duration, and the route between them |
| `"coffee shop"` near a point | A ranked list of real places nearby |

Four endpoints, one key, one response shape. We keep the parameter-level reference in the docs — this page is the pitch, not the manual: **[geolink-eg.com/docs →](https://geolink-eg.com/docs)**
